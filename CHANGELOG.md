# Changelog

All notable changes to AnyChat Translator are documented in this file and on
the [GitHub Releases](https://github.com/AdamTV/anychat/releases) page.

Entries are generated per release tag (`v*`) by
`scritps/generate_release_notes.sh`, which groups commits by
conventional-commit type (`feat`, `fix`, `docs`, `chore`, ...). The `Release`
workflow (`.github/workflows/release.yml`) prepends each release section here
automatically when a tag is pushed.
